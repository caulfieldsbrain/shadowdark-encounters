# Shadowdark Encounters

Create and manage Shadowdark RPG encounters directly inside Obsidian.

Shadowdark Encounters is a companion plugin to Shadowdark Statblocks that helps GMs quickly build encounter notes using monsters stored in their vault.

> ⚠️ Early Development Release (v0.1.0)
>
> This plugin is currently under active development and APIs, note formats, and features may change before the first stable release.

---

## Features

### Encounter Builder Wizard

Create encounters using a guided three-step workflow:

1. Select monsters
2. Add optional encounter details
3. Preview the generated encounter note

### Monster Browser

Browse monsters from your vault with:

- Search
- Level filtering
- Tag filtering
- Sorting
- Quick previews

### Monster Previews

Preview monster information directly from the encounter builder:

- Level
- AC
- HP
- Attacks (when available)

Quick actions include:

- Open monster note
- Open in new tab
- Open to the right
- Copy monster path

### Encounter Notes

Generated encounters include:

- Encounter summary
- Monster roster
- Party information
- Setup notes
- Read-aloud text
- Tactics
- Treasure
- GM notes

All encounter data is stored as standard markdown notes.

---

## Optional Integration

Shadowdark Encounters is designed to work independently, but integrates naturally with:

- Shadowdark Statblocks

When used together, monsters imported or created with Shadowdark Statblocks can be quickly added to encounters.

## Installation

### Manual Installation

1. Download the latest release.
2. Extract the files into: .obsidian/plugins/shadowdark-encounters/
3. Enable **Shadowdark Encounters** in Obsidian's Community Plugins settings.
